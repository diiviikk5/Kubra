# 🇮🇳 Kubra — The Citizen Superlayer for India's Open Network

> Built for the **"Build What Moves India"** Hackathon (Varun Mayya x OpenAI).  
> A high-performance, intent-driven citizen coordination superlayer built on **ONDC (Open Network for Digital Commerce)** and **Beckn Protocol v1.0.0**.

---

## 🎯 The Visceral Problem
> **“I shouldn’t need to know which app sells what. I should just be able to ask India for the best way to buy something.”**

In India today, citizens juggle half a dozen fragmented platforms (Zepto for 10-min groceries, Amazon for electronics, local hardware stores for replacement parts, separate apps for 9 different Metros and city buses). 

**Kubra** replaces app fragmentation with a **single, natural language & vision intent interface**. One prompt queries thousands of decentralized ONDC seller nodes, decomposes multi-seller orders, guarantees lowest landed pricing, and executes 1-click UPI checkout with FIFO logistics.

---

## ⚡ Key Features

1. **Ask India Engine (Powered by OpenAI Vyapar LM)**
   - Decomposes natural language queries (Hindi/English/Voice) across multiple independent ONDC seller nodes.
   - Compiles **Multi-Seller Carts** (e.g. 5kg Atta from local Kirana + Mixer Blade from DigiBazaar hardware store) into a single combined delivery run.
   - Saves 20–30% vs quick-commerce dark stores with **zero surge or hidden handling fees**.

2. **Interactive Matter.js Physics Typography**
   - Interactive gravity letter canvas in the center of the landing page where letters (`K U B R A`) and network tags drop, collide, bounce, and can be tossed with the mouse.

3. **YatriSetu Dynamic Multimodal Transit**
   - Single composite dynamic QR ticket spanning Metro + BEST/DTC City Bus + Bharat Taxi feeder.
   - Real-time delay auto-recovery with zero cancellation penalty.

4. **Auto-IGM Dispute & 60-Second UPI Reversal**
   - Computer vision unboxing audit cross-matches package weight delta (-39%) and transit shock sensors (4.8G) to settle disputes in 60 seconds instead of 14 days.

5. **Beckn Protocol Inspector Drawer**
   - Real-time JSON contract inspector for hackathon judges validating Beckn v1.0 `/search`, `/select`, `/init`, `/confirm`, and `/issue` payloads.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router) + React 18
- **Styling**: Tailwind CSS + Glassmorphism
- **Physics Engine**: Matter.js (React Bits FallingText)
- **Protocol**: Beckn Protocol Core v1.0.0 (ONDC Core)
- **AI Engine**: OpenAI GPT-4o Vision & Vyapar LM Intent Parser
- **Icons & Effects**: Lucide React + Canvas Confetti

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/diiviikk5/Kubra.git

# Navigate to project directory
cd Kubra

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
